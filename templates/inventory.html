Existing / Legacy Account


                    

                        Use this path for older hosts that already
                        have a usable account such as
                        root, lou, or

                        Add/Edit Host form exactly as entered.

                        You may be prompted for the target account
                        password. The password is not stored by HIMP.
                        This command also enrolls the target host key
                        into HIMP's known_hosts file.
                    


                    

                        

                        
                    


                    

                        2. Run on the HIMP server — verify SSH
                    


                    

                        

                        
                    


                    

                        

                            3. Run on the HIMP server — verify Become

                            The result must show

                        pong. A Become-enabled host

Dedicated HIMP Automation Account


                    

                        Recommended final settings:
                        
                            Ansible User = himp-automation
                        
                        and
                        Become = enabled.
                    


                    

                        1. Run on the HIMP server — transfer the HIMP public key
                    


                    

                        The username currently entered in Add/Edit Host
                        is treated as the bootstrap account only.
                        This step may prompt for that account's password.
                    


                    

                        

                        
                    


                    

                        2. Run on the TARGET HOST as root
                    


                    

                        This creates the locked
                        himp-automation account,
                        installs the HIMP public key, creates the
                        Ansible sudo policy, and validates sudoers.
                    


                    

                        

                        
                    


                    

                        3. Run on the HIMP server — verify SSH
                    


                    

                        

                        
                    


                    

                        4. Run on the HIMP server — verify passwordless sudo
                    


                    

                        This must return
                        uid=0(root)
                        without requesting a password.
                    


                    

                        

                        
                    


                    

                        5. Run on the HIMP server — verify Ansible + Become
                    


                    

                        The successful result should return
                        0.
